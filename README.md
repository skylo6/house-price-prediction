# house-price-prediction using Machine Learning
Project Overview
This project focuses on predicting house prices using Machine Learning techniques and Python. The goal is to build a predictive model that learns from historical housing data and estimates house prices based on relevant property features. 
this project demonstrates the application of supervised machine learning in solving a real-world regression problem
Objectives
Explore and understand housing data
Perform data processing and cleaning
Identify features that influence house prices
Train a machine Learning regression model
Evaluate the model's prediction performance
Technologies used
python
pandas
Numpy
Matplotlib
Scikit- learn
Project workflow
Data collection and exploration
data preprocessing 
feature selection
model trainig
model evaluation
house price prediction
Machine Learning approach
this project  uses supervised learning because the model is trained using historical data containing known house prices. 
the task is a regression problem since the model predicts continuous numerical values
